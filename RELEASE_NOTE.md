# LKMS UI v0.0.1

Primeira versão de lançamento

## Adições

### Componentes

#### Invólucros de conteúdo

- footerBase: Um rodapé base para futuros rodapés
- HeaderBase: Um cabeçalho base para futuros cabeçalhos
- MainBase: Um corpo de conteúdo base para futuros corpos de conteúdo
- footersBase: Um rodapé base para futuros rodapés
- NavigationBarBasic: Um barra de navegação básica

#### Heros

- HeroRoadmapBullet: Um roadmap com bullet para cada etapa
- HeroWithAside: Para exibição de dois conteúdos (Ex.: texto+imagem)
- HeroWithProducts: Um organizador de produtos simétrico

#### Independentes

- LineBasic: Uma linha básica
- LinkBasic: Um Link básico
- placeholderImage: Um simulador de imagens
